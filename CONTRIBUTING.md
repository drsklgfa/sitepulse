# Contribuindo

1. Abra uma issue descrevendo a mudança.
2. Crie uma branch a partir de `main`.
3. Mantenha regras de domínio nas camadas de serviço.
4. Inclua testes para comportamento novo ou corrigido.
5. Execute `make test` e `make validate`.
6. Atualize documentação e changelog quando necessário.
7. Abra um pull request usando o template.

Não inclua credenciais, cookies, tokens, dados pessoais ou conteúdo capturado sem autorização.
