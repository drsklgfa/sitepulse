# Política de segurança

Não publique vulnerabilidades exploráveis em issues públicas. Envie um relato privado pelo recurso **Security Advisories** do GitHub com:

- versão afetada;
- cenário de reprodução seguro;
- impacto;
- correção sugerida, quando disponível.

Nunca inclua tokens, credenciais, cookies de sessão ou dados reais no relato.
